# AgentPay AI

AgentPay AI is an autonomous AI agent that manages a crypto wallet and makes secure USDC payments.

## Features
- AI-powered payment automation
- USDC payments
- Circle Wallet integration
- Agent-to-agent transactions
- Recurring payments
- Real-time payment decisions

## Tech Stack
- HTML
- CSS
- JavaScript
- Circle Agent Stack
- USDC
